# Leave-Request-Management-System
An employee leave request and approval application built using the SAP ABAP RESTful Application Programming Model (RAP) with managed implementation and draft capabilities.

Final project Flow: 
Employee
   │
   └── Leave Request
          │
          ├── Create Leave Request
          ├── Edit Leave Request
          ├── Submit
          ├── Approve
          ├── Reject
          └── Cancel

The final application should demonstrate:

ABAP Cloud / RAP
CDS data modeling
Root and child entities
Associations
Composition
Managed RAP
Behavior Definition
Behavior Implementation
Determinations
Validations
Actions
Draft
Authorization
Value Help
UI annotations
Service Definition
OData V4 Service Binding
Fiori Elements UI
